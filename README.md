# Anatomy 3D AI Project

An interactive 3D human anatomy learning platform built using React Native, Expo, and Laravel backend.

## Features

* Interactive 3D Human Anatomy Models
* Organs & Skeletal System Visualization
* AI Assistant Chat Support
* Modern Medical Dashboard UI
* Real-time Model Rendering
* Anatomy Categories & Filtering

## Tech Stack

### Frontend

* React Native
* Expo
* WebView
* JavaScript

### Backend

* Laravel
* REST API

## Project Structure

frontend/ -> React Native App
backend/ -> Laravel API Server

## Installation

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
composer install
php artisan serve
```
